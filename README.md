# YouPage

Неофициальный Android-клиент для [EduPage](https://www.edupage.org) на Flutter и Material 3.
Главная идея: **оценки по умолчанию скрыты**, чтобы их не видели посторонние через плечо.

> Проект не связан с EduPage и не поддерживается компанией. У EduPage нет официального API,
> поэтому вход и получение оценок работают через веб-версию сайта и могут сломаться,
> если EduPage изменит свои страницы.

---

## Возможности

- **Режим приватности.** Оценки размыты (или заменены на «•••»).
  - Тап или долгое нажатие по оценке показывает её на 3 секунды.
  - Кнопка с глазом в шапке включает и выключает режим целиком.
  - Состояние «раскрыто» нигде не сохраняется, а скрытие работает только на уровне отрисовки.
  - Скрытые оценки недоступны для чтения скринридером.
- **Material You.** Динамические цвета Android 12+, скругления 28dp, светлая, тёмная и AMOLED-темы.
- **Анимации.** Плавное размытие и раскрытие, переход «карточка → экран предмета», плавный переход входа.
- **Оценки по предметам.** Список предметов, средний балл, последние оценки, экран предмета с датами.
- **Безопасное хранение.** Данные входа лежат в Android Keystore (`flutter_secure_storage`).
- **Демо-режим.** Можно посмотреть интерфейс на тестовых данных без входа.

## Как получить готовый APK

1. Откройте раздел **Releases** этого репозитория.
2. Скачайте `app-release.apk` из последнего релиза.
3. Откройте файл на телефоне и разрешите установку из неизвестных источников.

Каждый релиз также содержит `youpage-source.zip` с исходным кодом проекта.

Если релизов ещё нет, откройте вкладку **Actions**, выберите последний успешный запуск
и скачайте файл из **Artifacts → youpage-apk**.

## Как использовать

1. На экране входа введите **адрес школы**: часть до `.edupage.org`.
   Например, для `myschool.edupage.org` вводится `myschool`.
2. Введите логин и пароль от EduPage.
3. Откройте экран оценок. Они будут скрыты: коснитесь оценки, чтобы увидеть её.
4. В меню (три точки) можно переключить маску на точки, включить AMOLED-тему, выбрать тему и выйти.

Чтобы посмотреть интерфейс без аккаунта, нажмите **Демо-режим**.

## Автоматическая сборка (GitHub Actions)

Файл `.github/workflows/build.yml` собирает APK при каждом пуше в `main` или `master`,
а также вручную (Actions → Run workflow).

Что делает сборка:
1. Создаёт актуальную Android-обвязку командой `flutter create`.
2. Добавляет разрешение на интернет и название приложения.
3. Выполняет `flutter build apk --release`.
4. Загружает APK в Artifacts и публикует релиз `build-N` с APK и архивом исходников.

Если релиз не создаётся, откройте **Settings → Actions → General → Workflow permissions**
и включите **Read and write permissions**.

APK подписывается отладочным ключом. Для личной установки этого достаточно,
для публикации в магазинах приложений нужен собственный ключ подписи.

## Локальная сборка

Нужны Flutter (stable) и JDK 17.

```bash
flutter create --platform=android --org com.youpage --project-name youpage /tmp/scaffold
rm -rf android && cp -r /tmp/scaffold/android android
# добавьте в android/app/src/main/AndroidManifest.xml перед <application>:
#   <uses-permission android:name="android.permission.INTERNET"/>
flutter pub get
flutter run            # запуск на устройстве или эмуляторе
flutter build apk --release
```

Папка `android/` не хранится в репозитории: она генерируется при сборке.

## Известные ограничения

- Парсер оценок написан с расчётом на формат страницы `/znamky/` и не проверен на всех школах.
  Если вход проходит, а оценок нет, сообщение на экране поможет понять причину.
- Приложение показывает только оценки. Расписание, сообщения и домашние задания пока не реализованы.
- Пароль хранится на устройстве в защищённом хранилище, чтобы приложение могло входить автоматически.
  Кнопка «Выйти» удаляет его.
