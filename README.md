# YouPage

Кастомный клиент EduPage (Flutter, Material 3). Оценки скрыты по умолчанию.

## Как получить APK
1. Создайте пустой репозиторий на GitHub и загрузите в него ВСЁ содержимое этого архива (включая скрытую папку `.github`).
2. Откройте вкладку **Actions** → «Сборка APK» (запустится сама; либо Run workflow).
3. Через 5–8 минут: Actions → запуск → **Artifacts → youpage-apk**, либо раздел **Releases**.
4. Установите `app-release.apk` на телефон (разрешите установку из неизвестных источников).

Если сборка упала — пришлите лог шага, который покраснел.
